# Живой граф

Интерактивная демонстрация изменений ориентированного графа: 1250 вершин,
плотность около 10%, обновление 1–5 вершин каждые 10 секунд.

Вершины закреплены на одной окружности. Удаляемые вершины и их связи выделяются
красным, добавляемые — зелёным. Изменения показаны в центре и в панели событий.
После 5 секунд подсветки следует 3 секунды перехода; чёрные связи добавленных
вершин затем затухают за 2 секунды.

Колёсико мыши или кнопки +/− меняют масштаб. Перетаскивание перемещает карту,
кнопка «Вписать» возвращает общий вид. Поддерживается увеличение двумя пальцами.
Нажатие на вершину или её имя показывает входящие и исходящие связи.

## Запуск

Откройте `index.html` в браузере. Сборка, зависимости и сервер не требуются.
Данные синтетические и генерируются в браузере.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку `main`, папку `/ (root)`.
